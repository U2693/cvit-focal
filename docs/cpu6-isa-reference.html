CPU6 ISA reference notes

This is a working reference for the subset of Centurion CPU6 implemented by biscvit. It reflects emulator behavior and observations from the bootstrap/WIPL image; it is not yet a complete vendor manual.

Registers and levels

CPU6 has 16 byte registers per level, grouped as 8 word pairs:

PairBytesCommon name
AXAH:ALAccumulator
BXBH:BLSecondary accumulator
RTRH:RLReturn register
DXDH:DLData/index
EXEH:ELOften device base / index
SPSH:SLStack pointer
GXGH:GLGeneral
HXHH:HLGeneral

The emulator models interlevel registers as register banks addressed by (level << 4) | register. For example IL6(A) is word 0060. The word pairs are A,B,X,Y,Z,S,C,P; in emulator names these are AX,BX,RT,DX,EX,SP,GX,HX. WIPL installs its MUX input interrupt entry with SAR 6,P, so the emulator treats level-6 P/HX as the level-6 interrupt PC. WIPL polls IL6(A) for terminal input:

0588: E6 60    ILLD IL6(AX),AX
058A: 45 10    XFRB AL,AH
058C: 14 FA    BZ 0588

Branch opcodes use an 8-bit signed offset from the instruction following the offset byte.

1BNCC clear
2BNN set
3BPN clear
4BZZ set
5BNZZ clear
6BLT/BNL-ishC clear in current emulator
7BGE/BP-ishN clear

Addressing modes

Load/store and jump groups use low opcode bits as addressing mode selectors. Implemented forms include:

ModeMeaning
0Immediate operand at PC
1Direct 16-bit address
2Indirect through 16-bit direct address
3PC-relative direct
4PC-relative indirect
5Indexed form
6-7Register pair direct

Indexed operands include register selection, optional auto-increment/decrement, optional displacement, and optional indirection. Example from WIPL:

05F4: 95 A4    LD AX,@[SP]    ; load AX through a pointer stored at SP

Calls, returns, and stack

CALL stores the current RT on the stack, sets RT to the return PC, and jumps. RSR jumps to RT and restores the prior RT from the stack.

05AF: 7F 81    POP EH..EL
05B1: 09       RSR

Interrupts

EI/DI set and clear the emulator's interrupt-enable flag. Queued terminal input raises a level-6 interrupt when enabled and when level 6 has a non-zero P/HX vector. Interrupt entry saves the current level, PC, and flags internally, switches to level 6, jumps to IL6(P), and disables nested interrupts. RI restores the saved frame. This is enough for WIPL's MUX routine at 05A6 to read F201 and leave the character in IL6(A).

Terminal conventions observed in WIPL

WIPL normalizes printable terminal input by setting the high bit. For example, pressing ASCII '1' yields AL=B1 while AH may retain 31:

058E: C0 80    LDB BL,#80
0590: 43 31    ORB AL,BL      ; '1' => B1

High-bit control characters seen in the line editor include 88 backspace-like, 8D carriage return, and 95 line-kill/cancel-like.
