cvit system diagram

cvit is the native Hawk/Disk6 personality for biscvit. It boots a resident kernel, loads SYSTEM/COMMAND, and currently uses a mix of kernel vectors and emulator-assisted SVCs while the filesystem and tools are brought up.

Disk image model

out/os.img Hawk image

sector 0x0000       boot sector
sector 0x0012..17   SYSTEM UAL / allocation list
sector 0x0020       SYSTEM directory page 0
sector 0x0021..     SYSTEM member payload sectors

400-byte Hawk payload sector = 2 cvit pages of 200 bytes
member allocation is sector-aligned; even empty files get one sector

System call ABI

Programs call cvit services with SVC $40:

AX = function selector
BX = control block pointer
SVC $40
AXFunctionControl block
0001console putcCB+0: byte character

Unknown selectors currently print ?SVC and return.

FQFN rules

[device:][path/]name

H0: Hawk platter 0
H1: Hawk platter 1

Examples: ZEP, H1:ZEP, /SYSTEM/ZEP, H0:/SYSTEM/TEST. Missing device defaults to H0:; missing path defaults to the current prefix, initially /SYSTEM.

Near-term cleanup direction
